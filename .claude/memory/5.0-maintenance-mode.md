# 5.0 is in maintenance mode

Decided by Thomas, 2026-09-29.

- Do not improve testing in the `5.0` tree: no new tests, no tests ported from main, no fuzz
  corpus or sweep work. What it has is enough.
- The one exception: fixing an issue in 5.0 adds a regression test, one that fails without
  the fix, so the bug cannot come back.
- Coverage work goes into main. Porting between trees flows 5.0 -> main only.
